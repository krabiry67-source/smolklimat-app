# Как собрать APK СмолКлимат — подробно

## Что было не так в первой сборке
1. **Приложение открывалось с рамкой телефона и панелью «Экраны 1a…»** — это служебная обвязка прототипа. Внутри Android-приложения страница не узнавала, что она «в приложении», и показывала её.
   Исправлено тремя способами сразу: на узких экранах (телефон) рамка и панель скрываются всегда; приложение помечает себя в User-Agent (`SmolKlimatApp`); после загрузки страницы приложение само включает полноэкранный режим.
2. **Значок** — был синий кружок. Теперь логотип (снежинка + пламя) на прозрачном фоне, все размеры: `res/mipmap-*/ic_launcher.png`.
3. Добавлен `gradle.properties` (`android.useAndroidX=true`) — без него сборка с AndroidX может падать.

## Способ 1. GitHub Actions (рекомендую, ничего не ставить)

### Первый раз
1. Зарегистрируйтесь на github.com → **New repository** → имя `smolklimat-app` → **Public** → Create.
2. На странице репозитория: **Add file → Upload files**. Перетащите **содержимое** архива так, чтобы в корне репозитория лежали:
   ```
   .github/workflows/build-apk.yml
   android/settings.gradle.kts
   android/build.gradle.kts
   android/gradle.properties
   android/app/...
   ```
   ⚠ Папка `.github` скрытая — в Windows включите «Показывать скрытые файлы», на телефоне загружайте с компьютера. Если её нет, сборка не появится во вкладке Actions.
   Можно создать файл вручную: **Add file → Create new file**, имя `.github/workflows/build-apk.yml`, вставить содержимое.
3. **Commit changes**.

### Сборка
4. Вкладка **Actions** → слева **Build APK** → **Run workflow** → Run.
5. Ждите 4–7 минут, пока кружок не станет зелёной галочкой. Красный крестик — откройте его, скопируйте текст ошибки и пришлите мне.
6. Откройте завершённый запуск → внизу **Artifacts** → `smolklimat-apk` (скачается zip, внутри `smolklimat-1.0.0.apk`).
   **Проверка:** нормальный APK весит **3–8 МБ**. Если файл десятки килобайт — это не APK (обычно html-страница или пустой архив), его ставить нельзя.

### Установка на телефон
7. Перешлите APK на телефон (MAX, Telegram, кабелем).
8. Откройте файл → Android попросит разрешить установку из этого источника → **Разрешить** → **Установить**.
9. **Если стояла старая версия с рамкой — сначала удалите её** (долгое нажатие на значок → Удалить). Иначе установка может выдать «Приложение не установлено»: первая сборка подписана другим временным ключом.

### Выпуск версии для клиентов и кнопки «Обновить»
10. **Releases → Create a new release** → Choose a tag: `v1.0.0` → Publish. Сборка запустится сама и прикрепит APK к релизу.
11. Следующая версия: тег `v1.0.1`, `v1.1.0` и т.д. — кнопка «Обновить» в приложении найдёт её.
12. В Tweaks прототипа впишите `githubRepo` = `ваш_логин/smolklimat-app` (или скажите мне — впишу в сборку).

## Постоянный ключ подписи (сделать до раздачи клиентам)
Без своего ключа каждая сборка GitHub подписывается разным временным ключом, и обновление поверх не установится.

На компьютере с Java (или попросите Claude на VPS):
```
keytool -genkey -v -keystore release.jks -alias smolklimat -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.jks > release.txt
```
GitHub → репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:
- `KEYSTORE_BASE64` — содержимое `release.txt`
- `KEYSTORE_PASSWORD` — пароль хранилища
- `KEY_ALIAS` — `smolklimat`
- `KEY_PASSWORD` — пароль ключа

**`release.jks` и пароли сохраните в двух надёжных местах.** Потеряете — выпустить обновление поверх установленного приложения будет невозможно.

## Способ 2. Собрать на вашем VPS через Claude
Скопируйте папку `android` на сервер и дайте задание:
```
В папке android лежит Android-проект (Kotlin, Gradle Kotlin DSL).
1. Установи OpenJDK 17, Android command-line tools, platform android-34, build-tools 34.0.0, Gradle 8.7. Прими лицензии sdkmanager.
2. Создай android/local.properties с sdk.dir.
3. Выполни gradle assembleRelease в папке android.
4. Скопируй app/build/outputs/apk/release/app-release.apk в /opt/smolklimat/public/smolklimat.apk и покажи размер файла.
```
Тогда APK можно скачать по ссылке `https://api.smolclimate.ru/smolklimat.apk`.
