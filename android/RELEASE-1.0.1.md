# СмолКлимат 1.0.1

## Что нового
- Каталог smolclimate.ru открывается прямо в приложении, на весь экран, с кнопкой «Заказать монтаж»
- Фото услуг: установка, обслуживание, ремонт, диагностика, демонтаж
- Загрузка фото к заявке (до 3 шт., до 5 МБ) с запросом доступа к галерее
- Запрос разрешения на уведомления
- Подсказки адресов Смоленска, свободный ввод адреса, удаление адресов
- Регистрация и вход через сервер — аккаунт работает на новом телефоне
- Новый значок «Услуги» в нижнем меню

## Как выпустить
1. На VPS: `cd android && gradle assembleRelease --no-daemon` (versionName уже 1.0.1, versionCode 2).
2. Проверить размер APK (3–10 МБ), переименовать в `smolklimat-1.0.1.apk`.
3. github.com/krabiry67-source/smolklimat-app → Releases → Create a new release → тег `v1.0.1` → вставить текст «Что нового» → прикрепить APK → Publish.
   Или через Claude на VPS:
   `gh release create v1.0.1 smolklimat-1.0.1.apk --repo krabiry67-source/smolklimat-app --title "СмолКлимат 1.0.1" --notes-file RELEASE-1.0.1.md`

Если тег `v1.0.1` уже существует — выпускайте как `v1.0.2` и поменяйте версию в `android/app/build.gradle.kts` и `APP_VERSION` в приложении.
